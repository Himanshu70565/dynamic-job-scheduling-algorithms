# Dynamic Job Scheduling Algorithms

This repository contains Jupyter notebook implementations of dynamic job scheduling strategies and their performance analysis.

## Notebooks

- `fcfs_job_scheduling.ipynb` — First Come First Serve (FCFS) dynamic scheduling.
- `spt_job_scheduling.ipynb` — Shortest Processing Time (SPT) dynamic scheduling.
- `edd_job_scheduling.ipynb` — Earliest Due Date (EDD) dynamic scheduling (including static comparison).

## Getting Started

1. Install Python 3 and Jupyter Notebook.
2. Open this repository.
3. Run any notebook to explore the scheduling logic and metrics.

## Goal

Compare scheduling approaches using common job metrics such as flow time and tardiness.
